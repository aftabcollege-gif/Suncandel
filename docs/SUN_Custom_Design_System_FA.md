# SUN Custom Design System

## Brand DNA
- Luxury
- Handmade
- Premium
- Trust
- Modern

## Design Personality
- سطوح با کیفیت متریال‌محور
- تایپوگرافی قوی و readable در RTL
- روایت‌محور در صفحات Conversion
- تعادل بین حس لوکس و سرعت استفاده

## Typography Strategy
### Persian
- Primary: Vazirmatn
- Fallback: IRANSansX, Tahoma, Arial

### Latin
- Primary: Inter
- Fallback: Segoe UI, Arial

### Scale
- H1: 48px
- H2: 36px
- H3: 28px
- Body: 16px
- Caption: 13-14px

## Color & Theme System
- هر Theme دارای:
  - semantic colors
  - layout density
  - motion style
  - interaction style

## Component Rules
- Cards: داستان + اعتماد + اقدام
- Buttons: اولویت واضح + بازخورد لمسی
- Forms: کم‌اصطکاک + فوکوس قابل مشاهده
- Navigation: context چندپرسونا + branding store
- Dashboards: decision-ready, not widget-only

## UX Quality Guardrails
- ممنوع: generic bootstrap-like layout
- الزامی: visual hierarchy مشخص، CTA واضح، trust indicators
